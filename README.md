# Bantu Saya - GitHub Achievements Automations & Tracker

Repositori ini digunakan sebagai repositori publik untuk mengaktifkan dan menguji pencapaian (Achievements/Badges) resmi GitHub secara mandiri dan transparan.

---

## 🏆 Ringkasan Status GitHub Achievements (ardianryan)

| Badge | Nama Badge | Status | Cara / Syarat Mendapatkan |
| :---: | :--- | :---: | :--- |
| ⚡ | **Quickdraw** | ✅ Dimiliki | Menutup issue atau pull request dalam < 5 menit setelah dibuat. |
| 🪂 | **YOLO** | ✅ Dimiliki | Melakukan merge Pull Request tanpa code review / review requirement. |
| 🦈 | **Pull Shark** | 🔄 Terproses (Otw Silver) | Menggabungkan Pull Request (Bronze = 2 PR, Silver = 16 PR, Gold = 128 PR). |
| 👯 | **Pair Extraordinaire** | 🔄 Terproses (Otw Bronze) | Co-author commit pada PR yang di-merge (Default = 1 PR, Bronze = 10 PR, Silver = 24 PR). |
| 🧠 | **Galaxy Brain** | ⏳ Butuh 2 Akun/Rekan | Mendapatkan minimal 2 jawaban yang ditandai *Accepted Answer* di GitHub Discussions. |
| 🌟 | **Starstruck** | ⏳ Butuh Komunitas | Memiliki repositori publik dengan minimal 16 stars. |
| 💖 | **Public Sponsor** | 💡 Mandiri ($1) | Mensponsori pengembang open source melalui GitHub Sponsors (min. $1). |
| ❄️ | **Arctic Code Vault** | 🔒 Pensiun | Berkontribusi pada repositori sebelum snapshot arsip GitHub tahun 2020. |
| 🚀 | **Mars 2020** | 🔒 Pensiun | Berkontribusi pada repo yang dipakai misi helikopter Mars Ingenuity NASA 2020. |
